# M4 Verilog 해석기 + 1장 1-5~1-11 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 폰과 PC에서 Verilog 조합 회로를 직접 써 보고 자동 채점받을 수 있게 하고, 1장 나머지 단원(1-5~1-11)을 배포한다.

**Architecture:** `src/sim/verilog`에 렉서 → 파서(AST) → 정교화(모듈 인스턴스 펼치기 + 정적 검사) → 평가기(조합 로직을 안정될 때까지 반복)를 둔다. 값은 32비트 이하 2값(0/1) 비트벡터(`number`)다. 과제 종류에 `verilog`를 더하고, 채점기는 TS로 따로 쓴 기대 함수(`spec`)와 비교한다(해석기 버그가 모범 답안과 같이 틀려 숨는 것을 막는다). 편집기는 textarea + 줄 번호 + 기호 버튼 줄.

**Tech Stack:** TypeScript, Vite, Vitest, vite-plugin-pwa. 런타임 의존성 없음.

**Spec:** `docs/superpowers/specs/2026-11-21-hw-study-tool-design.md` (§4 1장, §5 그리기/Verilog 표, §6.3 Verilog 해석기, §6.4 Task, §6.5 Verilog 편집기, §7-4, §8)

## Global Constraints

- 모든 문구는 한국어, 코드·식별자는 영어. 초보자 눈높이.
- 공개 저장소: 문서·코드·단원 내용에 사용자 개인 정보(일정, 신상 등)를 쓰지 않는다.
- 런타임 의존성 추가 금지. 해석기는 직접 작성.
- 지원 문법(§6.3): `module`/`endmodule`, ANSI 포트(`input`/`output`/`output reg`, `[n:0]`), `wire`, `reg`, `localparam`, `assign`, `always @(*)`, `begin`/`end`, `if`/`else`, `case`/`endcase`/`default`, `=`, 연산자 `~ & | ^ ! && || == != < <= > >= + - << >> ?:`, `a[3]`, `a[3:0]`, `{}`, `4'b1010`/`8'd5`/`8'hFF`/10진수, 같은 파일 모듈 인스턴스(`.a(x)`).
- 지원 안 함: `initial`, `#지연`, `$display` 등, `generate`, `function`/`task`, z, signed → "이 앱에서는 아직 지원하지 않아요".
- 오류 메시지: 한국어, 줄 번호 + 고칠 힌트. 예: "3번째 줄: 세미콜론(;)이 빠졌어요."
- 테스트 벤치는 앱이 제공한다. 사용자는 모듈만 작성한다.
- 단원 id·부품 이름은 배포 후 바꾸지 않는다. 저장 형식 변경은 마이그레이션 + fixture 테스트(이번에는 `work` 값에 문자열을 넣을 뿐이라 형식 변경 없음).
- 모든 과제의 reference는 통과, wrong은 각각 실패(content.test가 검증).

## Review Focus

1. 끝나지 않는 조합 루프(`assign a = ~a;`, 서로 물린 assign) → 정해진 횟수 뒤 "조합 루프(발진)" 오류, 멈춤 없음. → Task 2
2. 자기 자신/서로를 인스턴스하는 모듈 → 무한 재귀 없이 오류. → Task 2
3. 틀린 문법(빠진 `;`, `end` 없음, 닫히지 않은 괄호, 빈 파일, 모르는 기호) → 크래시 없이 줄 번호 붙은 한국어 오류 1개. → Task 1
4. 아무 곳에서도 값을 넣지 않은 출력, 입력에 대입, `assign`으로 reg에 대입 / always 안에서 wire에 대입, 같은 신호 여러 곳 대입 → 정적 검사 오류. → Task 2
5. 저장된 코드가 문자열이 아니거나(손상) 아주 긺 → 뼈대 코드로 시작, 채점은 오류 안내만. → Task 4

### Task 1: 렉서와 파서

**Files:**

**Interfaces:**
- Produces: `class VerilogError extends Error { line: number }` (메시지는 `"${line}번째 줄: ..."` 형식), `parse(src: string): SourceFile` (`SourceFile = { modules: ModuleDecl[] }`). AST는 `ast.ts`에 정의: `ModuleDecl {name, ports: Port[], items: Item[], line}`, `Port {dir: "input"|"output", isReg, width, name}`, `Item` = `decl`(wire/reg/localparam) | `assign` | `always`(stmt) | `instance`(module, name, conns: Record<string, Expr>), `Stmt` = `block` | `if` | `case` | `assign`(lhs, rhs, line), `Expr` = `num`(value, width?) | `id` | `index` | `range` | `unary` | `binary` | `ternary` | `concat`.

- [ ] **Step 1: 실패 테스트** — `parse`가 다음을 처리하는지:
  - 2입력 AND 모듈(`assign y = a & b;`)의 포트 3개·assign 1개
  - `output reg [6:0] seg` + `always @(*) case (d) 4'd0: seg = 7'b0111111; default: seg = 0; endcase`
  - 리터럴 `4'b1010`=10(width 4), `8'hFF`=255, `8'd5`=5, `12`=12(width 없음), `4'b10_10`=10
  - 연산자 우선순위: `a | b & c` = `a | (b & c)`, `a + b << 1` = `(a + b) << 1`, `s ? a : b`
  - 인스턴스 `half_adder h1(.a(x), .b(y), .s(s0), .c(c0));`
  - 오류(메시지에 줄 번호 포함): 빠진 `;` → `"2번째 줄: 세미콜론(;)이 빠졌어요"` 포함, `endmodule` 없음, `initial` → "지원하지 않아요", `#5` → "지원하지 않아요", `@(posedge clk)` → "2장에서" 포함, 빈 문자열 → "module" 포함, `y = 3'b129` 같은 잘못된 숫자.
- [ ] **Step 2: 실행해 실패 확인** — `npx vitest run src/sim/verilog/parser.test.ts` → FAIL (모듈 없음)
- [ ] **Step 3: 구현** — 손으로 쓴 렉서(`//`, `/* */` 주석 무시, 토큰마다 line) + 재귀 하강 파서(우선순위 등반). 너비 32 초과 선언은 오류 "이 앱은 32비트까지만 지원해요". `posedge`는 Ruling: M4에서는 "순차 회로(posedge)는 2장에서 배워요" 오류(M5에서 지원).
- [ ] **Step 4: 실행해 통과 확인** — 같은 명령 → PASS
