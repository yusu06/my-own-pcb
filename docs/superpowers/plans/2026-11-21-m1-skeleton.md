# 마일스톤 1: 앱 뼈대 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 폰에서 홈 화면에 추가해 오프라인으로 0-1 단원(의뢰서 → 개념 카드 → 실제 기기에서는 → 퀴즈)을 끝까지 진행할 수 있는 PWA를 GitHub Pages에 배포한다. 실습 과제는 아직 없다.

**Architecture:** Vite + TypeScript 정적 앱. 로직(퀴즈 채점, 저장/마이그레이션, 진행 상태, 라우팅, 본문 파싱)은 DOM이 없는 순수 함수 모듈로 만들고 Vitest로 테스트한다. 화면은 `src/ui/`에서 DOM을 직접 만들고, 브라우저 미리보기로 검증한다. 오프라인 캐시와 업데이트 알림은 vite-plugin-pwa(prompt 모드)가 담당한다.

**Tech Stack:** TypeScript, Vite, Vitest, vite-plugin-pwa, GitHub Actions(Pages 배포)

**Spec:** `docs/superpowers/specs/2026-11-21-hw-study-tool-design.md` (§6.4, §6.5, §6.6, §6.7, §7의 1번)

## Global Constraints

- 저장소 루트 = `hw-study-tool/`. 배포 주소 기준 경로 `base: '/my-own-pcb/'`.
- 의존성은 devDependencies만 사용한다: `vite`, `typescript`, `vitest`, `vite-plugin-pwa`. 런타임 의존성 0개. `package-lock.json`은 커밋한다.
- TypeScript `strict: true`.
- 모든 화면 문구는 한국어로 쓴다. 코드와 식별자는 영어.
- 폰 세로 화면 우선. 375px 폭에서 가로 스크롤 금지. 터치 대상 최소 44px.
- 색상은 `:root` CSS 변수로 정의하고 다크 모드를 지원한다(`prefers-color-scheme` + `[data-theme]` 덮어쓰기).
- 단원 본문을 `innerHTML`로 넣지 않는다(`textContent`/DOM 생성만).
- 저장소 접근(`localStorage`)은 전부 try/catch로 감싼다. 실패해도 앱은 동작해야 한다.
- 단원 id(`"0-1"` 형식, 정규식 `^\d-\d{1,2}$`)와 저장 키는 한 번 배포하면 바꾸지 않는다.
- 원본 게임(IT THINKS)의 이름, 문구, 그래픽을 쓰지 않는다.

## Review Focus

1. **저장소를 못 쓰는 환경**(시크릿 모드, 용량 초과, `localStorage` 접근 시 예외): 앱은 정상 동작하고 "진행 상황이 저장되지 않아요" 경고만 뜬다. → Task 4 테스트
2. **깨진 저장 데이터 / 미래 버전 / 엉뚱한 백업 파일**: 기존 데이터를 지우지 않는다. 깨진 원본은 `hw.corrupt`에 보관한다. 잘못된 백업 파일을 불러오면 현재 데이터는 그대로 두고 한국어 오류를 보여준다. → Task 4 테스트
3. **숫자 퀴즈 입력 변형**(`" 150 "`, `"150Ω"`, `"150 mA"`, 전각 `"１５０"`, `"0,15"`, 빈 칸): 공백·단위·전각 숫자를 허용하고, 쉼표는 소수점으로 본다. 빈 칸은 오답이 아니라 "숫자를 입력하세요"로 처리한다. → Task 3 테스트
4. **단원 도중 이탈·새로고침, 또는 업데이트로 단원 단계 수가 줄어든 경우**: 같은 단계에서 이어 하고, 저장된 단계가 범위를 넘으면 마지막 유효 단계로 맞춘다. → Task 5 테스트
5. **단원 진행 중 새 버전 도착**: 자동으로 새로고침하지 않고 배너만 띄운다. 적용 직전에 `hw.backup.prev`에 스냅샷을 저장한다. → Task 4 테스트(스냅샷) + Task 9 검증

export type Step = { kind: "client" } | { kind: "concept"; i: number } | { kind: "task"; i: number }
  | { kind: "realWorld"; i: number } | { kind: "quiz" } | { kind: "done" };
export function lessonSteps(l: Lesson): Step[];        // client, concept×n, task×n, realWorld×n, quiz, done

export function lessonState(id: string, d: SaveData, lessons: Lesson[]): LessonState;
export function nextLessonId(d: SaveData, lessons: Lesson[]): string | null; // 순서상 done/skipped가 아닌 첫 단원
export function openLesson(id: string, d: SaveData, lessons: Lesson[], now: number): SaveData; // 앞의 미완료 단원을 skipped로, 대상은 started로(이미 done이면 유지)
