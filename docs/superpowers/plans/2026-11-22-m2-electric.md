# 마일스톤 2: 전기 회로 실습 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 폰에서 부품을 놓고 선을 이어 전기 회로를 만들면 즉시 시뮬레이션되고(전구·LED 켜짐, LED 탐, 합선), "테스트 실행"으로 자동 채점되는 실습을 0장 7단원 전부에 넣는다.

**Architecture:** 직류 해석기(`src/sim/electric`)는 DOM 없는 순수 모듈로, 모든 부품을 컨덕턴스 + 전류원으로 바꾼 절점 해석(nodal analysis)을 가우스 소거로 풀고, LED·다이오드·트랜지스터는 상태를 바꿔 가며 반복한다. 채점기(`src/grader/electric.ts`)는 스위치 조합을 전부 돌려 단원 데이터의 검사 목록을 평가한다. 편집기는 순수 상태 리듀서(`src/editor/state.ts`)와 SVG 화면·터치 입력(`src/editor/view.ts`, `input.ts`)으로 나눈다.

**Tech Stack:** TypeScript, Vite, Vitest (M1과 같음, 새 의존성 없음)

**Spec:** `docs/superpowers/specs/2026-11-21-hw-study-tool-design.md` (§5 0장, §5.1, §6.3 전기 회로 해석기, §6.4, §6.5 회로 편집기, §6.6, §6.7, §8)

## Global Constraints

- 런타임 의존성 0개. 새 devDependency 없음.
- 단원 id와 저장 키는 바꾸지 않는다(`hw.save`, `hw.backup.prev`, `hw.corrupt`). 저장 형식 변경은 `MIGRATIONS`에 추가하고 `src/store/fixtures/`의 이전 버전 샘플로 테스트한다.
- 폰 세로 화면 우선, 375px 폭 가로 스크롤 금지, 터치 대상 최소 44px. 선 연결은 "핀 탭 → 다른 핀 탭"(spec §6.5).
- 모든 화면 문구는 한국어. 단원 본문은 `textContent`/DOM으로만 넣는다.
- 공개 저장소: 문서·코드·단원 내용에 사용자 개인 정보(일정, 신상 등)를 쓰지 않는다.
- 전기 수치는 이 계획의 "부품 상수" 표 값을 그대로 쓴다(spec §9에서 빌더에게 맡긴 값을 여기서 확정).

### 부품 상수 (`src/sim/electric/parts.ts`)

| 부품 kind | 핀 | 모델 | 값 |
|---|---|---|---|
| `battery` | `+`, `-` | 전압원 V + 내부저항 | 기본 V=3, 내부저항 0.1Ω |
| `resistor` | `a`, `b` | 저항 | `value` Ω (기본 100) |
| `lamp` | `a`, `b` | 저항 30Ω | 켜짐: 전류 ≥ 10mA, 밝기 = min(I/0.1, 1) |
| `led` | `a`(애노드), `k`(캐소드) | 구간 선형 다이오드 | Vf 2.0V, 직렬저항 5Ω, 켜짐 ≥ 1mA, 밝기 = min(I/0.02,1), **탐: I > 30mA** |
| `switch` | `a`, `b` | 토글(눌러서 켜고 끔) | 닫힘 0.01Ω, 열림 = 연결 없음 |
| `button` | `a`, `b` | 평상시 열림(누르는 동안 닫힘) | 위와 같음 |
| `button-nc` | `a`, `b` | 평상시 닫힘(누르는 동안 열림) | 위와 같음 |
| `npn` | `b`, `c`, `e` | B–E: 다이오드(Vf 0.7, 10Ω), C–E: 스위치 | Ib ≥ 0.05mA면 C–E 1Ω, 아니면 열림 |

- 모든 노드에 접지로 1e-9 S(gmin)를 넣어 떠 있는 노드에서도 행렬이 풀리게 한다.
- 합선: 어떤 전지든 전류 > 2A면 `short: true`.
- 다이오드 반복은 최대 20회. 수렴하지 않으면 `converged: false`.

- 방법: 접지 = 첫 번째 전지의 `-` 넷(전지가 없으면 모든 전압 0, 모든 부품 꺼짐). 전지는 노턴 등가(컨덕턴스 1/RBAT, 전류원 V/RBAT), 닫힌 스위치·저항·전구는 컨덕턴스. 모든 노드에 GMIN. 이 Task에서는 LED/npn을 열림(연결 없음)으로 둔다(Task 4에서 채움).
- [ ] **Step 1: 실패하는 테스트**(허용 오차 1e-3)
  - 3V 전지 + 100Ω 저항: 저항 전류 ≈ 3/100.1 A.
  - 전지 + 버튼 + 전구: 안 눌림 → 전구 off, 전류 ≈ 0. 눌림 → 전류 ≈ 3/30.11, on.
  - 분압: 100Ω–100Ω 직렬, 가운데 핀 전압 ≈ 1.5V(내부저항 고려, ±0.01).
  - 병렬 스위치 2개 + 전구(OR): 4조합 → off,on,on,on. 직렬 스위치 2개(AND) → off,off,off,on.
  - **덜 만든 회로**: 전지 없음 → 모든 nodeV 0, 모두 off. 선 하나도 없음 → NaN 없음(`Object.values(nodeV).every(Number.isFinite)`).
  - **합선**: 전지 `+`–`-`를 선으로 직결 → `short === true`.

### Task 4: LED · 다이오드 · 트랜지스터

**Files:**
- Modify: `src/sim/electric/solve.ts`
- Test: `src/sim/electric/solve.test.ts`

- 방법: 각 다이오드형 소자(LED, npn의 B–E)는 상태 on/off를 가진다. 처음엔 모두 off. 풀고 나서 off인데 V(a)−V(k) > Vf면 on, on인데 계산 전류 < 0이면 off로 바꾸고 다시 푼다. on은 컨덕턴스 1/Rs + a←k 방향 전류원 Vf/Rs. npn의 C–E는 그 반복에서 B–E 전류 ≥ IB_ON이면 RCE_ON 컨덕턴스. MAX_ITER 넘으면 `converged: false`(마지막 해는 그대로 반환).
- [ ] **Step 1: 실패하는 테스트**
  - 3V + 100Ω + LED(바른 방향): 전류 ≈ (3−2)/(100+5+0.1) ≈ 9.5mA, on, burnt false.
  - 같은 회로 47Ω → ≈ 19.2mA, on, burnt false. 10Ω → ≈ 65.9mA, **burnt true**. 220Ω → ≈ 4.4mA(on, 1mA 이상).
  - 저항 없이 LED만 → burnt true(앱이 멈추지 않음).
  - **LED 거꾸로** → off, burnt false, 전류 ≈ 0.
  - npn: 버튼–10kΩ–B, E–전지(−), 전지(+)–100Ω–LED–C. 안 눌림 → LED off. 눌림 → LED on, 전류 ≈ 9.4mA(±0.5mA).
  - 모든 테스트에서 `converged === true`.
- [ ] **Step 2:** FAIL → **Step 3:** 구현 → **Step 4:** PASS.
- [ ] **Step 5: Commit** `feat(sim): piecewise-linear LED, diode and npn switch`
