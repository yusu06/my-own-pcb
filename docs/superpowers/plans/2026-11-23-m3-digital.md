# M3 디지털 시뮬레이터 + 부품함 + 1장 그리기 과제 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** NAND 기반 게이트 수준 시뮬레이터, 내가 만든 회로를 부품으로 저장하는 부품함, 0-6 게이트 다시 그리기와 1장 1-1~1-4 그리기 과제를 폰에서 공부할 수 있게 배포한다.

**Architecture:** 회로 데이터(`Part`/`Wire`/`Circuit`)와 터치 편집기는 M2 것을 그대로 쓰고, 부품 종류에 논리 부품(`nand`, `in`, `out`, `chip`)을 더한다. 편집기는 "회로 해석 어댑터"를 받아 전기/논리를 같은 화면에서 처리한다. 디지털 시뮬레이터는 칩을 NAND로 펼친(flatten) 뒤 단위 지연 방식으로 안정될 때까지 반복하며 0/1/X를 계산한다.

**Tech Stack:** TypeScript, Vite, Vitest, vite-plugin-pwa. 런타임 의존성 없음.

**Spec:** `docs/superpowers/specs/2026-11-21-hw-study-tool-design.md` (§5.1, §6.3 디지털, §6.4, §6.5, §6.6, §6.7, §7-3, §8)

## Global Constraints

- 모든 문구는 한국어, 코드·식별자는 영어. 초보자 눈높이.
- 공개 저장소: 문서·코드·단원 내용에 사용자 개인 정보(일정, 신상 등)를 쓰지 않는다.
- 런타임 의존성 추가 금지. 시뮬레이터는 직접 작성.
- 신호값은 0, 1, X 세 가지. 연결 안 된 입력은 X로 표시한다.
- 피드백 루프 허용. 일정 횟수(1000단계) 안에 안정되지 않으면 "발진" 오류.
- 점수 = NAND 환산 개수(칩은 내부 NAND 합산). `maxCost` + `costRequired`(true면 통과 조건, 아니면 ⭐만).
- 부품을 수정하면 새 버전으로 저장. 이미 그 부품을 쓴 회로는 저장 당시 버전 유지.
- 필요한 부품이 부품함에 없으면 기본 부품(코드에 든 기본 정의)을 회색으로 대신 쓴다. 원가는 정상 반영.
- 단원 id와 부품 이름(`not`, `and`, `or`, `xor`)은 배포 후 바꾸지 않는다.
- 저장 형식 변경은 마이그레이션 + 이전 버전 fixture 테스트.
- 모든 과제의 reference는 통과, wrong은 각각 실패(content.test가 검증). 원가 목표가 있으면 reference는 목표를 만족하고, 목표를 넘는 오답 하나를 넣는다.
- 편집기 화면 하나에 부품 약 30개까지.

## Review Focus

1. 연결 안 된 게이트 입력 → 출력 X, 채점은 "연결 안 된 입력" 안내로 실패(통과 금지). → Task 2, 5 테스트
2. 출력끼리 연결(입력 스위치 출력 + 게이트 출력 등, 구동원 둘 이상인 넷) → 충돌 오류, 크래시 없음. → Task 2
3. NAND 출력을 자기 입력에 연결한 루프(발진) → 1000단계에서 멈추고 "발진" 안내, 무한 루프 없음. → Task 2
4. 저장된 부품함이 손상되었거나(형식 오류, 자기 자신을 품은 칩) 단원을 건너뛰어 칩이 없음 → 기본 부품으로 대체, 깊이 제한으로 무한 재귀 없음. → Task 3, 4
5. 부품을 새 버전으로 고친 뒤에도 예전 회로는 예전 버전으로 동작(입출력 핀 수가 달라져도 깨지지 않음). → Task 4, 6

### Task 2: 디지털 시뮬레이터

**Files:**
- Create: `src/sim/digital/sim.ts`, `src/sim/digital/sim.test.ts`

**Interfaces:**
- Consumes: `pinNames`, `buildNets`, `pinKey`.
- Produces:
  - `type Bit = 0 | 1 | "X"`.
  - `type ChipLib = (ref: ChipRef) => { def: ChipDef; fallback: boolean } | null` (Task 3이 구현).
  - `interface ChipDef { inputs: string[]; outputs: string[]; circuit: Circuit }`: 칩 회로 안에서 입력은 `in` 부품(id = 입력 이름), 출력은 `out` 부품(id = 출력 이름).
  - `simulate(c: Circuit, inputs: Record<string, 0 | 1>, lib: ChipLib): DigitalResult`
    `interface DigitalResult { net: Record<string, Bit> /* pinKey → 값 */; out: Record<string, Bit> /* out 부품 id → 값 */; oscillating: boolean; conflict: boolean; missingChip: string | null }`.
  - `nandCost(c: Circuit, lib: ChipLib): number`.
- 규칙:
  - 칩은 재귀로 NAND까지 펼친다. 펼칠 때 내부 부품 id에 `칩id/` 접두어. 깊이 8을 넘거나 lib가 null이면 `missingChip = 칩 이름`, 해당 칩 출력은 X.
  - 구동원: `in` 부품의 y, NAND의 y. 한 넷에 구동원이 둘 이상이면 `conflict = true`, 그 넷은 X.
  - NAND: 입력 중 0이 있으면 1, 둘 다 1이면 0, 그 외 X. 넷 초기값 X. 한 단계에 모든 NAND를 이전 값으로 동시에 계산(단위 지연); 바뀐 게 없으면 멈춤; 1000단계면 `oscillating = true`.
  - 구동원 없는 넷은 X.

- [ ] Step 1: 실패 테스트 (모두 `ckt`로 회로 작성):
  - `NAND 진리표`: 00→1, 01→1, 10→1, 11→0
  - `연결 안 된 입력은 X`: b 미연결, a=1 → out X; a=0 → out 1 (0이면 X여도 1)
  - `NAND 두 개로 AND`: 11→1, 그 외 0, `nandCost` = 2
  - `출력끼리 연결하면 충돌`: in a.y와 in b.y를 같은 넷 → `conflict` true
  - `자기 루프 발진`: nand y→a, b에 in 1 → `oscillating` true (빠르게 끝남)
  - `SR 래치 유지`: NAND 2개 교차 결합, S̄=0→Q=1 후 S̄=1 유지 시 Q=1 (입력 바꿔 두 번 simulate: 두 번째 호출은 첫 결과 넷 값을 초기값으로 받는다 → 선택 인자 `prev?: Record<string, Bit>`)
  - `칩 펼치기`: NOT 칩(NAND 1개, a=b)을 lib로 주고 not 칩 회로의 out → 반전; 비용 1
  - `없는 칩은 X와 missingChip`, `자기 자신을 품은 칩은 깊이 제한에서 멈춤`
- [ ] Step 2: FAIL 확인
